# Primeira Aplicação Java

## Sobre o projeto

Este repositório reúne exercícios e projetos desenvolvidos durante meus estudos de Java, com o objetivo de praticar e aprimorar meus conhecimentos em programação.

## Conteúdos praticados

- Variáveis e tipos de dados
- Operadores aritméticos e lógicos
- Estruturas condicionais (`if`, `else` e `switch`)
- Estruturas de repetição (`while` e `for`)
- Entrada de dados com Scanner
- Manipulação de Strings
- Cálculos e operações matemáticas
- Lógica de programação

## Projetos desenvolvidos

- Conversor de temperatura
- Conversor de moedas
- Cálculo de fatorial
- Tabuada
- Sistema de conta bancária

## Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git e GitHub

## Objetivo

Registrar minha evolução no aprendizado de Java, desenvolver minha lógica de programação e construir uma base sólida para projetos futuros.
